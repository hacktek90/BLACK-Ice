Guide

Basics

  • Drag empty space to move the map.
  • Pinch (mobile) or scroll (desktop) to zoom.
  • Tap/click a node to select it.

Node actions

  • "Child" adds a child node to the selected node.
  • "Sibling" adds a node at the same level.

Links

  • Right‑click a node and choose "Link".
  • Then click another node to connect them.
  • Drag the control points on the line to adjust the curve.
